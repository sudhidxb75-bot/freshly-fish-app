# Freshly Mobile App UI V2 - FreshToHome-Inspired

This is a mobile-first PWA app design for Freshly.

It is inspired by modern fresh-food delivery apps, while keeping Freshly branding and Freshly backend features.

## Included design changes

- App-style compact mobile header
- Location selector on top
- Sticky mobile search bar
- Mobile category grid
- Fresh benefit chips
- App-style product cards
- Bottom navigation bar
- Mobile cart access
- PWA install support
- Existing backend and Google Apps Script connection preserved

## Upload files

Upload/replace these files and folders in GitHub:

```txt
index.html
track-order.html
assets/app.js
assets/config.js
assets/styles.css
assets/mobile-app.css
assets/mobile-app-v2.css
assets/mobile-app-v2.js
assets/pwa-install.js
manifest.webmanifest
service-worker.js
offline.html
assets/icons/
assets/freshly-logo-header.png
```

## Backend

No new backend is required for this UI revision.

It continues to use:

```txt
assets/config.js
```

and your existing Apps Script backend URL.

## Install on phone

Android Chrome:
- Open the Freshly website
- Tap browser menu
- Tap Add to Home screen / Install app

iPhone Safari:
- Open Freshly website in Safari
- Tap Share
- Tap Add to Home Screen
