# Freshly Mobile App V2.4 - Menu Dropdown Fix

This revision fixes the issue where the page appears behind the top menu dropdown.

## Fixed

- Top mobile menu now opens above the page with a dark backdrop.
- Background page scrolling is disabled while menu is open.
- Dropdown menu has a solid white background.
- Dropdown/submenu items are fully visible.
- Menu closes automatically after selecting a menu item.
- Menu closes by tapping outside or pressing Escape.
- Z-index conflicts with page/banner/search sections are fixed.
