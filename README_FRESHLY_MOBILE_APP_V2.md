# Freshly Mobile App V2 - FreshToHome-Inspired Design

This revision is based on the uploaded working PWA package.

## Included
- FreshToHome-inspired mobile app layout, adapted for Freshly
- Sticky location selector
- Sticky search bar
- Shop-by-category grid
- Freshly benefit chips
- Today-for-you offer cards
- App-style product cards
- Bottom navigation bar
- Visible Install App button
- Android/iPhone install instructions fallback
- Manifest, service worker and offline page

## Install App
Android Chrome: open the live HTTPS website and tap Install App.
iPhone Safari: Share > Add to Home Screen.

The install option needs HTTPS and may not appear in file preview, GitHub code preview, non-HTTPS links, or some in-app browsers.
